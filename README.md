# OOP-object-oriented-programming-project
The Movie Theater Booking System is a Java console-based application developed for an Object-Oriented Programming (OOP) project. It manages movies, snacks, customers, and bookings.
# About the Project
The Movie Theater Booking System is a console-based Java application designed to manage movie theater items and customer bookings.
The system supports two types of bookable items: movies and snacks. It maintains a catalog of available items, registers customers, processes booking and cancellation requests, and displays customer booking information.
# Project Objectives
* develop a Java-based Movie Theater Booking System using Object-Oriented Programming principles.
*  manage movie and snack information, including names, IDs, prices, genres, and company details.
*  register customers and maintain their booking records.
*  implement booking, cancellation, and item availability management.
*  provide item searching and alphabetical sorting functionality.
*  handle missing items using custom exception handling.
*  apply Java concepts : inheritance, abstraction, encapsulation, polymorphism, collections, lambda expressions, and streams.
*  practice object comparison and cloning.
# Features ✨
🎥 Movie and Snack Management

* Add movies and snacks to the catalog.
* Store item names, IDs, and prices.
* Store movie genres and snack company information.
* Check item availability.
* Display all catalog items.
* Sort items alphabetically by name.

👤 Customer Management

* Register customers using their IDs, names, and phone numbers.
* Store multiple booking records for each customer.
* Display registered customers.
* Check for active bookings before allowing a customer deletion operation.
* Compare customer objects and create customer copies.

🎟️ Booking Management

* Book available movies and snacks.
* Cancel bookings and restore item availability.
* Generate booking records containing a booking ID, date, status, customer, and booked item.
* Display bookings associated with a specific customer.

🔍 Search and Exception Handling

* Search for catalog items by ID.
* Use a custom MovieNotFoundException when an item cannot be found.
* Display error messages when a requested item does not exist.
# 🛠️ Technologies Used
* Programming Language: Java
* Programming Paradigm: Object-Oriented Programming (OOP)
* Collections: ArrayList and TreeSet
* Core Java Features: Interfaces, abstract classes, inheritance, encapsulation, and polymorphism
# ⚙️ How It Works
1. Creates a new movie booking system.
2. Adds two movies and two snack items to the catalog.
3. Registers two customers.
4. Displays all catalog items and registered customers.
5. Books a movie and a snack.
6. Creates booking records for successful bookings and associates them with a customer.
7. Displays the customer’s booking records.
8. Cancels a movie booking and restores its availability.
9. Sorts and displays catalog items alphabetically.
10. Tests exception handling by searching for a nonexistent item.
11. Tests customer deletion, object comparison, and cloning.
